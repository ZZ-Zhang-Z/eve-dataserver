# EVE Online 蹲站（单站做市）交易利润模型与物品选择推荐算法

> 配套文档：`docs/eve_market_overview.md`（市场微观结构速览）
> 实现脚本：`scripts/station_trading_recommender.py`（推荐算法）、`scripts/make_station_report.py`（可视化报告）
> 数据产物：`data/output/station_trading_recommendations.csv` / `.json`、`docs/station_trading_report.html`
> 分析基准：本地订单簿快照（Jita 4-4, location 60003760）+ 近 30 日成交历史

---

## 0. 结论先行

1. **蹲站的本质是单站做市（market-making）**，不是跨区套利：你在同一站点**同时挂买单与卖单**，靠捕获 `卖价 − 买价` 的价差获利，靠"改单"保持挂在盘口顶部来争取成交。
2. **任何一档价差必须覆盖往返费用**。在本机技能/声望参数下（经纪费 1.71%、交易税 4.2%），毛价差需 **> 8.1%** 才能不亏；这是硬门槛。
3. **顶层价差高度"失真"**：直接用最优一档买卖价算，93% 的物品都"赚钱"——但那是一两笔陈旧/垃圾挂单伪造的假象。用"小深度 VWAP + 垃圾单过滤"修正后，真实可交易候选为 **1,673 个**，中位净收益率 **15.9%**、中位毛价差 **25.3%**。
4. **流动性极度长尾**：候选物品日成交量中位仅 655 单位，但均值 250 万（弹药等少数品种贡献巨大），薄流动性陷阱普遍——高收益率 + 低成交量的物品要小仓位试单。
5. **推荐算法以"资本周转效率"为核心**，综合净收益率、日成交量、价格稳定、竞争宽松度打分排序，产出可直接交易的候选清单。

## 1. 蹲站交易是什么

| 维度 | 跨区套利（空间套利） | 蹲站 / 单站做市 |
| --- | --- | --- |
| 物理动作 | 低买 → 运输 → 高卖（跨星系/跨站） | 同站挂买卖单，原地周转 |
| 收益来源 | 地区/站点间价格差 | 同一订单簿的买卖价差（bid-ask spread） |
| 是否需运输 | 是（时间 + 货损风险） | 否 |
| 核心操作 | 比价、搬运 | 挂单、改单、抢盘口 |
| 资金形态 | 在途库存 | 站内挂单 + 站内库存 |

EVE 没有做空/杠杆/衍生品（见 `eve_market_overview.md` 第 1、6 节），所以蹲站只能做**现货多头的库存周转**：先以买单价吃进库存，再以卖单价出清，循环往复。你的角色相当于在 Jita 4-4 这个超级流动性池里当一个迷你做市商。

## 2. 利润模型（核心公式）

### 2.1 单笔往返净收益

设你挂的**买单（成为 bid）**价格为 `P_b`、`**卖单（成为 ask）**价格为 `P_a`（`P_a > P_b`）。成交时：

```
买入成本   = P_b × (1 + 经纪费 B)
卖出收入   = P_a × (1 − 经纪费 B − 交易税 T)
每单位净利 = 卖出收入 − 买入成本
          = P_a·(1−B−T) − P_b·(1+B)
净收益率   = 每单位净利 / 买入成本
```

> ⚠️ **方向陷阱**：蹲站是"买在 bid、卖在 ask"。若误写成"买在 ask、卖在 bid"（即吃卖单进货、砸给买单出货），则恒亏——这是本站早期脚本与大量同类工具的经典错误，本算法已修正。

### 2.2 费用盈亏平衡（硬门槛）

令净收益率 > 0：

```
P_a·(1−B−T) > P_b·(1+B)
⇒ P_a / P_b  >  (1+B) / (1−B−T)
```

代入本机参数 `B=0.0171, T=0.042`：

```
(1.0171) / (0.9409) = 1.0809
⇒ 毛价差 (P_a−P_b)/P_b 必须 > 8.09%
```

**含义**：只有毛价差超过 8.1% 的物品才值得做；且这仅是"不亏"线，要覆盖库存风险与机会成本，实盘建议净收益率 > 2%~3% 才纳入。

> 技能/声望越好，`B` 越低 → 门槛下降 → 可交易集合扩大。本模型的所有费率均由参数驱动，换号可直接调。

### 2.3 资本与周转

蹲站占用两类资金：**挂单资金**（买单挂出即锁仓）+ **库存资金**（已吃进待售）。若单次工作批为 `Q` 单位：

```
单次批 Q        = max(MIN_Q, TRADE_SHARE × 日成交量)      # 默认 TRADE_SHARE=1%
资本占用(近似)   = 买入成本 × Q                          # 双边资金滚动复用，按单边计
日可吃量        = 规划捕获份额 × 日成交量                 # 默认捕获 10%（BASE_SHARE）
日利润(规划)     = 每单位净利 × 日可吃量
日资本效率       = 日利润 / 资本占用  ≈  净收益率 × 周转次数
```

**核心洞察**：蹲站的制胜点不是单笔收益率，而是**周转次数 × 净收益率**。一个净收益率仅 5% 但每天能转 20 圈的物品，资本效率远高于一个净收益率 50% 但一周才转一圈的薄流动性物品。因此推荐算法把"资本效率"作为第二权重（0.25）。

### 2.4 库存风险

你持有时段内的价格下跌会侵蚀利润。用历史日均价变异系数 `σ = std(日均价)/mean(日均价)` 作为库存风险代理：σ 越低越安全。算法对高波动物品在评分中扣分（权重 0.15）。

## 3. 市场实证分析（基于真实数据）

### 3.1 数据规模

| 维度 | 数值 |
| --- | --- |
| `market_orders` 总行数 | 596,427 |
| Jita 星系（30000142）订单 | 329,980 |
| **Jita 4-4 站（60003760）订单** | **327,365**（占星系 99.2%，事实主市场） |
| 该站有挂单的物品种类 | 18,929 |
| 该站买卖双方齐备的种类 | 15,755（可蹲站 universe） |
| 成交历史覆盖 | 2026-05-24 ~ 2026-10-11（~140 天，15,216 种） |
| 改单事件（近 ~10h 窗口） | 181,265（modify 109,716 / insert 36,919 / delete 34,630） |

> 结论与 `eve_market_overview.md` 一致：**流动性高度集中于 Jita 4-4**，蹲站应锁定此站；其余站点深度低 1~2 个数量级，不适合做市。

### 3.2 关键发现一：顶层价差污染（最重要的坑）

直接用"最优卖价 − 最优买价"算净收益率，得到 **93.2% 的物品都赚钱**（中位毛价差竟达 216%）。这是**假象**：

- 某些物品存在"垃圾买单"（如百万物价上的 1 ISK 买单），使最优买价极低，伪造出巨大价差；
- 另一些是单笔陈旧挂单，快照瞬间拉开的临时缺口。

**修正方法**：
1. **垃圾单过滤**：剔除低于 `0.5 × 最优卖价` 的买单；
2. **小深度 VWAP**：价差按"日成交量 0.5%"的量在买卖盘各累计成交均价测算，而非单一最优档；
3. **费用门槛**：仅保留净收益率 > 2% 者。

修正后真实候选 **1,673** 个，分布健康：

| 指标 | 中位 | 均值 |
| --- | --- | --- |
| 毛价差 | 25.3% | — |
| 净收益率 | 15.9% | 26.3% |
| 日成交量 | 655 | 2,503,899 |
| 单物品日利润 | 2.81M ISK | — |
| 候选合计日利润 | — | 22.3B ISK |

### 3.3 关键发现二：费用门槛把机会集砍掉一大半

在垃圾单过滤后的 2,623 个"有量+有真实买盘"物品中，仅约 **64%** 的毛价差超过 8.1% 费用线。换言之，**约 1/3 看似能做的物品，实则被手续费吃光**。蹲站选品第一道筛子必须是费用盈亏平衡。

### 3.4 关键发现三：流动性长尾

日成交量的中位（655）与均值（250 万）相差 3 个数量级——少数弹药/矿种贡献了绝大多数成交量。这意味着：
- **高成交量品种**（弹药、同位素、机械部件）价差往往偏薄但极能放量，靠周转赚钱；
- **低成交量品种**常挂着夸张的高价差，但"买得到卖不出/卖得出买不进"，是薄流动性陷阱。

算法用 `top_ask_size / top_bid_size` 做可执行性判定，并在评分中对低量高收益品种不盲目加分（成交量权重 0.20 + 竞争权重 0.10 形成制衡）。

### 3.5 关键发现四：竞争由改单 churn 量化

`market_order_events` 显示近 10 小时窗口内 18 万次改单/挂撤，其中 **modify 10.9 万次**——说明盘口在被玩家高频改写。改单越频繁（churn 越高），你越难稳坐盘口顶部、越容易被插队，成交份额越低。算法以 `churn事件数 / 日成交量` 作为竞争强度，在评分中反向加权（权重 0.10）。

### 3.6 哪些品类适合蹲站

候选按市场分组 Top 包括：舰船装备（大型/中型/小型模块）、四大帝国派系装备、弹药、矿物、打捞材料、气云、深渊材料等。**最典型的高分品种**（见报告 Top 30）：铁质/各种族轨道弹、火箭、导弹、莫德合金、机械部件、电子元件、同位原矿——即"高频消耗、可预测需求、单位价适中"的工业与战斗耗材。这类物品每天被大量玩家买卖，价差虽不暴利但极能周转，是蹲站的黄金赛道。

## 4. 交易物品选择推荐算法

### 4.1 流程

```
① 载入 Jita 4-4 订单簿 → 按 type_id 分买卖盘（卖升序 / 买降序）
② 载入近 30 日成交历史 → 每物品日成交量 V、价格波动 σ
③ 载入改单事件 → 每物品竞争强度 churn
④ 逐物品计算：
   a. 垃圾买单过滤（bid < 0.5×最优卖价 剔除）
   b. 深度 D = max(MIN_Q, 0.5%×V)，买卖盘各算 VWAP → 收购价/出货价
   c. 净收益率 = [出货价×(1−B−T) − 收购价×(1+B)] / 收购价
   d. 日利润 = 净单位利 × 10%×V；资本 = 收购价×(1+B)×Q；资本效率 = 日利润/资本
⑤ 硬门槛：双方齐备 + 有历史 + V≥50 + 净收益率>2% + 盘口有量
⑥ 软打分（候选集内分位归一后加权）→ 排序
⑦ 补全物品名/分组 → 输出 CSV / JSON / 报告
```

### 4.2 评分函数

对通过门槛的候选，在候选集内做分位归一（5%~95% 截断，避免极端值主导），再加权：

```
Score = 100 × ( 0.30 · 净收益率(归一)
              + 0.25 · 资本效率(对数归一)
              + 0.20 · 日成交量(对数归一)
              + 0.15 · 价格稳定(=1 − 波动归一)
              + 0.10 · 竞争宽松(=1 − churn归一) )
```

| 因子 | 权重 | 含义 / 越大越好 |
| --- | --- | --- |
| 净收益率 | 0.30 | 单笔价差扣费后的收益厚度 |
| 资本效率 | 0.25 | 净收益率 × 周转，单位资金的日产出 |
| 日成交量 | 0.20 | 容量上限，决定能放多少量 |
| 价格稳定 | 0.15 | 1 − 波动率，库存下跌风险越低越好 |
| 竞争宽松 | 0.10 | 1 − 改单拥挤度，盘口越不被争抢越好 |

### 4.3 参数（可在脚本顶部调）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `BROKER` / `TAX` | 0.0171 / 0.042 | 经纪费 / 交易税（随技能变化） |
| `MIN_DAILY_VOLUME` | 50 | 日成交量下限（可执行性） |
| `DEPTH_SHARE` | 0.005 | 价差测算深度（日量 0.5%） |
| `TRADE_SHARE` | 0.01 | 单次工作批占日量比例 |
| `JUNK_BID_RATIO` | 0.5 | 垃圾买单过滤阈值 |
| `FEE_GATE_NET_MARGIN` | 0.02 | 净收益率门槛（2%） |
| `BASE_SHARE` | 0.10 | 规划捕获份额（日量 10%） |
| `W_*` | 见 4.2 | 五项评分权重 |

### 4.4 如何使用产物

- **`station_trading_recommendations.csv`**：可直接按 `score` 降序筛选，列为评分、净收益率、毛价差、买卖价、日成交量、波动、竞争、日利润、资本等。
- **`station_trading_recommendations.json`**：含每项全部分位子分（`n_profit` 等），便于二次加工/回测。
- **`station_trading_report.html`**：可视化（价差分布、Top20 评分、量×收益散点、分组集中度、Top30 表）。

运行：
```bash

.venv/Scripts/python.exe scripts/make_station_report.py
```

## 5. 风险、局限与实盘建议

1. **快照失真**：订单簿是单一时点（服务端 ~5 分钟缓存）。报告中 86% 毛价差的弹药，可能在你挂单瞬间被插队抹平。**务必高频刷新、小仓试单**，勿凭一次快照重仓。
2. **薄流动性陷阱**：高收益率 + 低日成交量的物品，价差"真实但无法放量"。算法已用深度/成交量制衡，但实盘仍建议对 `日成交量 < 200` 的品种单笔控制仓位。
3. **竞争插队**：churn 高的品种，你挂出后可能被更激进的改单者顶到盘口外，成交份额低于规划。可结合"改单节奏"自动化（本项目已落盘 `market_order_events`，可做改单速度指标）。
4. **库存风险**：持仓期间价格下跌直接吞噬利润；高波动物品（σ 大）慎做，或加快周转、降低单批。
5. **事件驱动**：版本更新、战争、资源改版会瞬间改写供需，历史参数需滚动窗口（建议 14~30 天），并对突发事件做人工复核。
6. **技能降费**：提升"贸易"相关技能与 NPC 声望可显著下移 8.1% 费用线，扩大可交易集合——这是蹲站玩家的核心成长曲线。

> 本算法是**初筛器**而非自动交易系统：它把"理论上能赚钱且容量足够"的物品推到你面前，但最终的下单价格、批大小、改单频率与风控，仍需结合实时盘口与你的资金曲线判断。
